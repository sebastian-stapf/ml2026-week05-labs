Kernel methods

A linear model on a feature map \(\phi(x)\) can bend to fit curved data. The kernel trick keeps that power while never writing \(\phi(x)\) down: every computation goes through \(K(x,z)=\langle\phi(x),\phi(z)\rangle\). Work through the five experiments in order, then try the questions.

5.3 · LMS with the kernel trick

Train β, never touch φ

Starting from \(\theta=0\), gradient descent keeps \(\theta=\sum_i\beta_i\phi(x^{(i)})\). So we update the \(n\) coefficients \(\beta\) with the Gram matrix \(K\) instead. Press play and watch the prediction \(\sum_i\beta_iK(x^{(i)},x)\) form as a sum of one curve per training point (faint lines).

\[\beta:=\beta+\alpha(\vec y-K\beta)\]\[\theta^\top\phi(x)=\sum_{i=1}^n\beta_iK(x^{(i)},x)\]Lecture eqs. (5.11)–(5.12)

5.4 · Kernels as similarity metrics

How similar is every point to z?

Drag the black diamond \(z\). The colour at each location \(x\) is \(K(x,z)\): blue for positive, orange for negative. The Gaussian kernel behaves like a similarity: a bump of width \(\sigma\) around \(z\). The linear and polynomial kernels do not; they grow with \(\|x\|\) along the direction of \(z\). The lecture warns that this intuition has flaws.

5.4 · Necessary and sufficient conditions

Is it really a kernel?

A symmetric \(K\) has a feature map exactly when every Gram matrix it produces is positive semidefinite (Theorem 5.1). Pick a candidate function and drag the points. One negative eigenvalue for one set of points is enough to rule a candidate out. Zero negative eigenvalues for a few sets proves nothing, but it is consistent with validity.

\[z^\top Kz=\sum_k\Big(\sum_i z_i\phi_k(x^{(i)})\Big)^2\ge 0\]Section 5.4, necessary condition

5.3 · Computational efficiency

What the trick saves, and what it costs

For all monomials of degree at most 3 (with repetitions), \(\phi(x)\) has \(p=1+d+d^2+d^3\) entries, yet \(\langle\phi(x),\phi(z)\rangle=1+t+t^2+t^3\) with \(t=\langle x,z\rangle\) costs \(O(d)\). The price is a dense \(n\times n\) Gram matrix: \(O(n^2)\) memory and \(O(n^2)\) work per full-batch update. Bars are on a logarithmic scale.

\[\langle\phi(x),\phi(z)\rangle=1+\langle x,z\rangle+\langle x,z\rangle^2+\langle x,z\rangle^3\]Lecture eq. (5.9)

K1Which feature map does \(K(x,z)=(x^\top z+c)^2\) correspond to?Take \(x,z\in\mathbb{R}^3\) and \(c\ge 0\). How many features are there, and how does \(c\) weight them?Worked answer
  1. Expand the square: \((x^\top z+c)^2=(x^\top z)^2+2c\,x^\top z+c^2\).
  2. Write the first term as a double sum: \((x^\top z)^2=\sum_{i,j}(x_ix_j)(z_iz_j)\).
  3. Write the middle term as \(\sum_i(\sqrt{2c}\,x_i)(\sqrt{2c}\,z_i)\) and the last as \(c\cdot c\).
  4. So \(K(x,z)=\langle\phi(x),\phi(z)\rangle\) with \(\phi(x)=[x_ix_j]_{i,j}\oplus[\sqrt{2c}\,x_i]_i\oplus[c]\). For \(d=3\) this is \(9+3+1=13\) features; in general \(d^2+d+1\).
  5. \(c\) sets the relative weight of the first-order terms \(\sqrt{2c}\,x_i\) against the second-order terms \(x_ix_j\).
Current result for x = (1, 2, −1), z = (0.5, −1, 2)
TakeawayComputing the 13-dimensional inner product explicitly and evaluating \((x^\top z+c)^2\) give the same number. The kernel needs only \(O(d)\) work instead of \(O(d^2)\).
K2Why must every kernel matrix be positive semidefinite?Assume \(K(x,z)=\phi(x)^\top\phi(z)\). Show \(z^\top Kz\ge 0\) for every vector \(z\).Worked answer
  1. Symmetry: \(K_{ij}=\phi(x^{(i)})^\top\phi(x^{(j)})=\phi(x^{(j)})^\top\phi(x^{(i)})=K_{ji}\).
  2. Expand: \(z^\top Kz=\sum_i\sum_j z_iK_{ij}z_j=\sum_i\sum_j\sum_k z_i\phi_k(x^{(i)})\phi_k(x^{(j)})z_j\).
  3. Move the sum over \(k\) outside: \(=\sum_k\big(\sum_i z_i\phi_k(x^{(i)})\big)\big(\sum_j z_j\phi_k(x^{(j)})\big)\).
  4. The two factors are equal, so \(z^\top Kz=\sum_k\big(\sum_i z_i\phi_k(x^{(i)})\big)^2\ge 0\).
Live check with K(x,z) = (xᵀz)², φ(x) = (x₁², x₁x₂, x₂x₁, x₂²)
Takeaway\(z^\top Kz\) is a squared length in feature space, namely \(\|\sum_i z_i\phi(x^{(i)})\|^2\). It can never be negative.
K3Is \(K(x,z)=-\|x-z\|^2\) a valid kernel?It is symmetric and larger for closer points. Does that make it a kernel?Worked answer
  1. Take two distinct points with \(\|x^{(1)}-x^{(2)}\|=a>0\).
  2. The Gram matrix is \(K=\begin{bmatrix}0&-a^2\\-a^2&0\end{bmatrix}\), because \(K(x,x)=0\).
  3. Its eigenvalues are \(\pm a^2\). With \(z=(1,1)^\top\) we get \(z^\top Kz=-2a^2<0\).
  4. A valid kernel needs \(K\succeq 0\) for every finite point set, so this candidate fails. A shortcut: any valid kernel has \(K(x,x)=\|\phi(x)\|^2\ge 0\), and a zero diagonal with nonzero off-diagonal entries is never PSD.
Current result
Takeaway"Larger means more similar" is not enough. A kernel must be an inner product, and a quick test is whether a small Gram matrix has a negative eigenvalue.
K4What happens to the Gaussian Gram matrix as σ → 0 and σ → ∞?Use five distinct points on a line. What does each limit mean for the kernel regression of Experiment 2?Worked answer
  1. For \(i\ne j\), \(K_{ij}=\exp(-\|x^{(i)}-x^{(j)}\|^2/2\sigma^2)\). The diagonal is always \(K_{ii}=1\).
  2. \(\sigma\to 0\): every off-diagonal entry tends to 0, so \(K\to I\). Each point is similar only to itself. The fit interpolates the data with narrow spikes and predicts about 0 between them.
  3. \(\sigma\to\infty\): every entry tends to 1, so \(K\to\mathbf{1}\mathbf{1}^\top\), which has rank 1. All points look alike, and the prediction becomes nearly constant.
  4. For every finite \(\sigma>0\) and distinct points, \(K\) is positive definite, but its smallest eigenvalue shrinks quickly as \(\sigma\) grows. Gradient descent then needs many steps along those directions.
Current result, points x = 0, 0.5, 1, 1.5, 2
Takeaway\(\sigma\) sets the length scale on which two inputs count as similar. Too small memorises the data; too large blurs it.
K5When is the kernelised update cheaper than the explicit one?Compare one full-batch update of (5.3) in \(\theta\in\mathbb{R}^p\) with one update of (5.11) in \(\beta\in\mathbb{R}^n\).Worked answer
  1. Explicit: each of the \(n\) residuals \(y^{(i)}-\theta^\top\phi(x^{(i)})\) costs \(O(p)\), so one update costs \(O(np)\) and stores \(\theta\) with \(p\) entries.
  2. Kernel: computing \(K\beta\) with a precomputed dense \(K\) costs \(O(n^2)\). Building \(K\) once costs \(O(n^2d)\) kernel evaluations' worth of work and \(O(n^2)\) memory.
